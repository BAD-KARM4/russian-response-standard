# Guide for maintaining Russian Response Standard

Этот файл задаёт правила сопровождения репозитория и выпуска новых версий Skill.

## Источник истины

- SKILL.md задаёт поведение Skill и является основным источником истины.
- tests/regression.md содержит ручные регрессионные проверки и не входит в инструкции Skill.
- CHANGELOG.md фиксирует изменения поведения, упаковки и процесса выпуска.
- README.md описывает назначение, структуру и установку.
- agents/openai.yaml содержит интерфейсные метаданные.
- assets/icon.svg содержит иконку Skill.

## Изменения Skill

Перед добавлением нового правила проверь, не покрывается ли требуемое поведение существующим правилом.

Предпочитай:

1. уточнить существующее правило
2. объединить дублирующиеся правила
3. добавить новое правило только если существующая структура его не покрывает

Не расширяй SKILL.md только ради полноты описания.

При изменении поведения Skill:

- обнови версию в строке «Версия: vX.Y.Z» в SKILL.md
- добавь запись новой версии в начало CHANGELOG.md
- обнови или добавь регрессионный тест, если изменение можно проверить отдельным сценарием
- проверь, что новые правила не конфликтуют с жёсткими инвариантами

## Версии и релизы

GitHub Releases считаются неизменяемыми.

Если изменение затрагивает файл, который запускает release workflow, и должен быть опубликован новый релиз, сначала увеличь версию в SKILL.md.

Чистые изменения документации, которые не требуют нового installable пакета и не запускают release workflow, могут выполняться без изменения версии.

Новая запись CHANGELOG.md:

- располагается выше предыдущих версий
- описывает результат для пользователя или сопровождающего, а не историю отдельных коммитов
- содержит все существенные изменения текущего релиза
- после публикации не переписывается, кроме исправления фактической ошибки

Release workflow берёт описание GitHub Release из блока CHANGELOG.md с заголовком, совпадающим с текущей версией SKILL.md.

## Installable ZIP

В установочный архив входят только:

- SKILL.md
- agents/openai.yaml
- assets/icon.svg

README.md, CHANGELOG.md, AGENTS.md, tests и .github остаются только в репозитории.

## Проверки перед публикацией

Перед выпуском новой версии проверь:

- YAML frontmatter в SKILL.md валиден
- версия в SKILL.md совпадает с новой записью CHANGELOG.md
- для версии ещё не существует GitHub Release
- в SKILL.md нет Unicode em dash U+2014 и en dash U+2013
- изменения поведения покрыты существующими или новыми regression tests
- installable ZIP не содержит репозиторные служебные файлы
