# Changelog

## v1.4.7

- Добавлен CHANGELOG.md с восстановленной историей версий.
- Добавлен AGENTS.md с правилами сопровождения Skill и выпуска релизов.
- README.md дополнен ссылкой на историю изменений и правилами разработки.
- GitHub Release теперь получает описание из блока текущей версии в CHANGELOG.md вместо автоматически сгенерированных notes.
- Состав installable ZIP не изменён.
- Поведение Skill не изменено.

## v1.4.6

- Skill перестал без необходимости пересказывать уже известный пользователю контекст.
- Формализована работа с образцом авторского стиля пользователя.
- Усилена проверка сохранности фактов, условий, ограничений, причинно-следственных связей и степени уверенности после редактирования.
- Добавлено правило против бесполезного метатекста о структуре документа.
- Добавлены регрессионные тесты для новых правил.

## v1.4.5

- Добавлено правило: если два и более однородных элемента описываются по одинаковой структуре или одному признаку, предпочтителен маркированный список, если связный текст не нужен для логики.

## v1.4.4

- Запрещены Unicode em dash U+2014 и en dash U+2013 в собственной прозе Skill.
- Для тире используется один ASCII hyphen-minus с пробелами.
- Для диапазонов используется один ASCII hyphen-minus без пробелов.
- Обновлены примеры и финальная самопроверка под новое правило.

## v1.4.3

- Исправлен YAML frontmatter в SKILL.md: многострочное description теперь записано валидным YAML-блоком.

## v1.4.2

- Заменена иконка Skill на пользовательский SVG.

## v1.4.1

- Добавлены интерфейсные метаданные agents/openai.yaml и иконка Skill в релизный пакет.
- Installable ZIP ограничен файлами, необходимыми для установки Skill.
- Release workflow переведён на неизменяемые релизы: существующий тег не перезаписывается, для нового релиза требуется новая версия.

## v1.4

- Inline code полностью запрещён в обычном тексте ответа.
- Code-оформление разрешено только в самостоятельных многострочных блоках для кода, команд и конфигураций.
- Зафиксирована версия, которая прошла регрессионную проверку после серии исправлений inline code.
- Skill перенесён в отдельный GitHub-репозиторий, добавлен набор ручных регрессионных тестов.

## v1.3

- Версия собрана заново от стабильной v1.1 после регрессии v1.2.
- Правило inline code упрощено и сделано более прямым.

## v1.2

- Усилены правила против inline code, произвольных числовых сценариев и небезопасных технических действий.
- Попытка чрезмерно усилить правило inline code привела к регрессии поведения и была заменена в следующих версиях.

## v1.1

- Inline code поднят в жёсткие инварианты ответа.
- Просьба оценить неизвестный параметр больше не считается основанием для произвольной сетки числовых сценариев.
- Предупреждение о разрушительном действии требуется непосредственно перед соответствующим блоком команд.

## v1.0

- Выполнен крупный рефакторинг Skill без добавления новых базовых принципов.
- Убраны дублирующиеся и конфликтующие правила.
- Структура сведена к 17 верхнеуровневым разделам.

## v0.13

- Точечно усилен синтаксический запрет inline code в прозе.
- Code blocks оставлены только для самостоятельных команд и конфигураций.

## v0.12

- Усилены ограничения на inline code.
- Ограничено использование формулировок от первого лица вроде «я бы выбрал» без прямого запроса пользователя.
- Запрещены произвольные числовые сценарии для неизвестных параметров.
- Для потенциально разрушительных технических действий закреплены диагностика до удаления и предварительное предупреждение.

## v0.11

- Усилено правило против декоративного жирного выделения, включая жирное первое содержательное предложение и основной вывод.

## v0.10

- Добавлены правила работы с артефактами ChatGPT Work.
- Формат файла выбирается по задаче, а не по длине ответа или возможностям Work.
- Зафиксированы правила редактирования существующих файлов и минимально достаточного состава артефактов.

## v0.9

- Добавлены правила поиска, внешних источников и пользовательских материалов.
- Зафиксирован приоритет первичных источников, проверка даты и версии, а также запрет на выдуманные ссылки и результаты проверки.

## v0.8

- Добавлены правила тона, формы обращения и рекомендаций.
- Ограничены искусственная дружелюбность, фамильярность и рекомендации от первого лица без запроса.

## v0.7

- Добавлены правила работы с неизвестными числовыми параметрами.
- Запрещена подстановка произвольных чисел ради конкретности.
- Диапазоны и сценарии требуют основания.

## v0.6

- Усилена дисциплина визуального форматирования ответа.
- Снижено декоративное использование выделений и технического оформления.

## v0.5

- Добавлены правила соразмерности ответа и остановки.
- Каждый новый блок должен добавлять информацию, влияющую на понимание, решение, безопасность или ограничения.
- Убраны обязательные повторные заключения и лишние дополнительные предложения.

## v0.4

- Добавлены правила английской технической терминологии.
- Добавлены правила выбора схем, таблиц и других визуализаций по задаче.

## v0.3

- Сформирована ранняя объединённая версия Russian Response Standard.
- Общие требования к русским ответам собраны в единый Skill и применяются автоматически в ChatGPT Work.
