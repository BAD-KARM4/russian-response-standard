# Russian Response Standard

Russian Response Standard задаёт единый стандарт качества ответов на русском языке. В каждом релизе доступны отдельные пакеты: навык для ChatGPT Work и плагин для ChatGPT Desktop.

## Что регулирует Skill

Skill задаёт правила для:

- прямых и соразмерных ответов без лишней риторики
- грамотного и естественного русского языка
- сохранения фактов, смысла, терминов и степени уверенности
- критической проверки предпосылок пользователя
- работы с неопределённостью и неизвестными параметрами
- технически точных и безопасных инструкций
- прозрачных расчётов
- обоснованных сравнений и рекомендаций
- работы с пользовательскими файлами и внешними источниками
- структуры, таблиц, визуализаций и артефактов Work
- устранения повторяющихся LLM-паттернов и лишнего канцелярита
- полного запрета inline code в обычной прозе

## Структура репозитория

- `SKILL.md` - инструкции и правила Skill
- `CHANGELOG.md` - история изменений по версиям
- `AGENTS.md` - правила сопровождения и выпуска новых версий
- `agents/openai.yaml` - метаданные интерфейса ChatGPT
- `assets/icon.svg` - иконка Skill
- `tests/regression.md` - набор ручных регрессионных тестов
- `scripts/validate-package.py` - автоматическая проверка целостности пакета
- `scripts/build-plugin.py` - сборка и проверка плагина из основного навыка
- `.github/workflows/validate.yml` - проверка пакета при push и pull request
- `.github/workflows/release.yml` - автоматическая проверка, сборка и публикация релиза

## Использование

На странице GitHub Releases выберите нужный архив:

- `russian-response-standard-skill-vX.Y.Z.zip` - навык для ChatGPT Work. Он содержит `SKILL.md`, `agents/openai.yaml` и `assets/icon.svg`.
- `russian-response-standard-plugin-vX.Y.Z.zip` - плагин для ChatGPT Desktop. Он содержит манифест и тот же навык в папке `skills/`.

Плагин собирается из основного SKILL.md. В его копии описание расширено на Chat и Work, а интерфейсная подсказка не использует синтаксис Codex. Остальные правила навыка совпадают с основным пакетом.

После установки плагин становится доступен в новых чатах. ChatGPT может выбрать навык по описанию задачи, но установка сама по себе не гарантирует его применение к каждому ответу. Если навык и плагин установлены одновременно, они остаются отдельными копиями одной версии.

После изменений в Skill прогоните контрольные запросы из `tests/regression.md`. Регрессионные тесты не входят в инструкции Skill и не должны влиять на его поведение.

## История изменений

Изменения каждой версии фиксируются в [CHANGELOG.md](CHANGELOG.md).

GitHub Release использует запись соответствующей версии из CHANGELOG.md как release notes.

## Разработка

Изменение поведения Skill сопровождается новой версией, записью в CHANGELOG.md и регрессионной проверкой, когда для изменения можно сформулировать отдельный тест.

Перед публикацией оба пакета автоматически проверяются скриптом `scripts/validate-package.py`. Release создаётся только после успешной проверки.

Опубликованные релизы не изменяются задним числом. Подробные правила сопровождения находятся в [AGENTS.md](AGENTS.md).
